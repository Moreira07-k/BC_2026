IMPORTANTE:

O Painel Administrativo NÃO deve ser acessível pelo site público.

O cliente jamais deverá visualizar qualquer botão, link, menu ou referência ao painel administrativo.

O painel deverá existir em uma rota completamente separada do site, por exemplo:

/admin

ou outra rota privada.

Essa rota deve ser protegida por autenticação.

Somente dois usuários terão acesso ao sistema administrativo:

• Administrador Principal (Eu) • Proprietária da Confeitaria

Qualquer outro usuário deverá ter o acesso negado.

O painel deve possuir:

• Tela de Login exclusiva • Email • Senha • Recuperação de senha • Sessão segura • Logout • Controle de permissões

Após o login, apenas esses usuários poderão acessar:

• Dashboard • Pedidos • Produtos • Estoque • Banner • Promoções • Comentários • Clientes • Relatórios • Configurações

Nenhuma funcionalidade administrativa deve aparecer no site público.

O cliente deve enxergar apenas:

• Página Inicial • Cardápio • Carrinho • Comentários • Contato • Perfil do Cliente (caso esteja logado)

Toda a administração do sistema deve ocorrer exclusivamente dentro do painel administrativo protegido por autenticação.
