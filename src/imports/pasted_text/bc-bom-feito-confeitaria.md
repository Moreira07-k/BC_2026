Atue como um Desenvolvedor Full Stack Sênior especializado em React, Vite, TailwindCSS, Firebase, Framer Motion e UI/UX.

Seu objetivo é desenvolver um projeto profissional de e-commerce completo para uma confeitaria, seguindo boas práticas de arquitetura, código limpo (Clean Code), componentes reutilizáveis, responsividade, performance e segurança.

O projeto deve ser totalmente funcional, organizado e pronto para produção.

==================================================
QUALIDADE
==================================================

O projeto deve ser escrito de forma profissional.

Cada componente deve ficar em um arquivo separado.

Não concentrar muito código em um único arquivo.

Sempre comentar as partes importantes.

Usar boas práticas de React.

Criar um README.md ensinando como instalar e executar o projeto.

Ao finalizar cada etapa, validar se o sistema continua funcionando antes de prosseguir para a próxima.

Não gerar código incompleto ou apenas exemplos. O objetivo é entregar um sistema completo, funcional, organizado e pronto para deploy no Firebase Hosting.
